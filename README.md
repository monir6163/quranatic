# কুরআনী রুকিয়াহ পেপার — ল্যান্ডিং পেজ + অ্যাডমিন প্যানেল

Node.js + Express.js + MongoDB (Mongoose) + EJS + TailwindCSS দিয়ে তৈরি একটি সম্পূর্ণ ডাইনামিক ল্যান্ডিং পেজ, যেখানে অ্যাডমিন প্যানেল থেকে পুরো পেজের সব কন্টেন্ট (টেক্সট, ছবি, দাম, লিংক) পরিবর্তন করা যায়। পুরো সাইট রেসপনসিভ (মোবাইল/ট্যাব/ডেস্কটপ) এবং স্ক্রল-অ্যানিমেশন সহ তৈরি।

## ফিচার

- **পাবলিক ল্যান্ডিং পেজ**: হিরো, সমস্যা সেকশন, সমাধান সেকশন, তুলনামূলক ("কেন আলাদা") সেকশন, প্রশ্নোত্তর, গ্রাহক রিভিউ স্লাইডার, অর্ডার/প্রাইসিং সেকশন, স্টিকি মোবাইল অর্ডার বার, হোয়াটসঅ্যাপ ফ্লোটিং বাটন।
- **অ্যাডমিন প্যানেল** (`/admin`): লগইন সুরক্ষিত, প্রতিটি সেকশনের আলাদা এডিট পেজ, কার্ড/প্রশ্ন/রিভিউ যোগ ও মুছার সুবিধা, ছবি আপলোড (লোগো, হিরো থাম্বনেইল, গ্যালারি ছবি), পাসওয়ার্ড পরিবর্তন।
- **রঙের থিম**: গাঢ় সবুজ (emerald) + হাতির দাঁত রঙের ব্যাকগ্রাউন্ড + অ্যান্টিক গোল্ড অ্যাকসেন্ট — রেফারেন্স সাইটের হলুদ থিম থেকে আলাদা করে ডিজাইন করা হয়েছে।
- **অ্যানিমেশন**: স্ক্রল-এ রিভিল, হোভার ইফেক্ট, টেস্টিমোনিয়াল স্লাইডার, হিরোতে ফ্লোটিং ব্যাকগ্রাউন্ড শেপ।

## প্রয়োজনীয় জিনিস

- Node.js 18+ 
- MongoDB (লোকাল ইনস্টল অথবা MongoDB Atlas ফ্রি ক্লাস্টার)

## ইনস্টলেশন ও রান করার ধাপ

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ২. .env ফাইল তৈরি করুন (.env.example থেকে কপি করুন)
cp .env.example .env
# .env ফাইলে আপনার MONGODB_URI, SESSION_SECRET, ADMIN_USERNAME, ADMIN_PASSWORD ঠিক করে দিন

# ৩. Tailwind CSS বিল্ড করুন (একবারই যথেষ্ট, কারণ অ্যাডমিন শুধু টেক্সট/ছবি পরিবর্তন করে, নতুন ক্লাস যোগ করে না)
npm run build:css

# ৪. প্রথম অ্যাডমিন ইউজার ও ডিফল্ট কন্টেন্ট তৈরি করুন (একবারই চালাবেন)
npm run seed

# ৫. সার্ভার চালু করুন
npm start
# ডেভেলপমেন্টের সময় (auto-restart): npm run dev
```

সার্ভার চালু হলে:
- পাবলিক সাইট: `http://localhost:3000`
- অ্যাডমিন লগইন: `http://localhost:3000/admin/login`
  - ডিফল্ট ইউজারনেম/পাসওয়ার্ড: `.env` এ যা দিয়েছেন (ডিফল্ট: `admin` / `admin123`)
  - **লগইন করার সাথে সাথে "পাসওয়ার্ড" মেনু থেকে পাসওয়ার্ড পরিবর্তন করে নিন।**

## CSS নিয়ে গুরুত্বপূর্ণ নোট

Tailwind CSS প্রি-বিল্ড করা থাকে (`public/css/output.css`)। আপনি যদি `views/*.ejs` ফাইলে নতুন কোনো Tailwind ক্লাস যোগ করেন (ডিজাইন পরিবর্তন করতে চাইলে), তাহলে আবার বিল্ড করতে হবে:

```bash
npm run build:css
# অথবা ডেভেলপমেন্টের সময় লাইভ দেখতে:
npm run watch:css
```

শুধু টেক্সট/ছবি/দাম পরিবর্তন করলে (অ্যাডমিন প্যানেল দিয়ে) — CSS আবার বিল্ড করার দরকার নেই।

## প্রজেক্ট স্ট্রাকচার

```
├── server.js                 # মূল Express সার্ভার
├── config/db.js              # MongoDB কানেকশন
├── middleware/
│   ├── auth.js                # অ্যাডমিন সেশন অথ মিডলওয়্যার
│   └── upload.js               # ছবি আপলোড (multer)
├── models/
│   ├── Admin.js                # অ্যাডমিন ইউজার মডেল
│   └── Content.js              # সব ল্যান্ডিং পেজ কন্টেন্ট (singleton ডকুমেন্ট)
├── routes/
│   ├── public.js               # পাবলিক পেজ রুট
│   └── admin.js                # অ্যাডমিন প্যানেল রুট (CRUD)
├── views/
│   ├── index.ejs               # পাবলিক ল্যান্ডিং পেজ
│   ├── partials/               # হেডার, ফুটার, হেড, অ্যাডমিন লেআউট
│   └── admin/                  # অ্যাডমিন প্যানেলের প্রতিটি পেজ
├── public/
│   ├── css/                    # Tailwind input/output
│   ├── js/main.js              # স্ক্রল রিভিল, FAQ, স্লাইডার
│   └── uploads/                # আপলোড করা ছবি
└── scripts/seed.js             # প্রথম অ্যাডমিন ও ডিফল্ট কন্টেন্ট তৈরি
```

## অ্যাডমিন প্যানেল থেকে যা যা পরিবর্তন করা যাবে

| সেকশন | কি পরিবর্তন করা যাবে |
|---|---|
| সাইট সেটিংস | সাইট নাম, লোগো, দাম, মেয়াদ, ফোন, হোয়াটসঅ্যাপ, অর্ডার বাটনের টেক্সট/লিংক |
| হিরো | ব্যাজ, শিরোনাম, হাইলাইট শব্দ, বিবরণ, পয়েন্ট লিস্ট, ভিডিও লিংক ও থাম্বনেইল |
| সমস্যা | কার্ড যোগ/মুছুন, প্রতিটি কার্ডের টাইটেল ও বিবরণ |
| সমাধান | টেক্সট কন্টেন্ট, গ্যালারি ছবি আপলোড/মুছুন |
| কেন আলাদা | দুই কলামের তালিকা ও বক্স টেক্সট |
| প্রশ্নোত্তর | প্রশ্ন যোগ/মুছুন |
| গ্রাহক রিভিউ | রিভিউ যোগ/মুছুন |
| ফুটার | পরিচিতি, নোট, কপিরাইট টেক্সট |

## নিরাপত্তা সংক্রান্ত পরামর্শ (প্রোডাকশনে দেওয়ার আগে)

- `.env` ফাইলের `SESSION_SECRET` একটি লম্বা র‍্যান্ডম স্ট্রিং দিয়ে পরিবর্তন করুন।
- সিডিং এর পর ডিফল্ট অ্যাডমিন পাসওয়ার্ড (`admin123`) অবশ্যই পরিবর্তন করুন।
- `NODE_ENV=production` সেট করুন এবং HTTPS এর মাধ্যমে সাইট হোস্ট করুন।
- MongoDB Atlas ব্যবহার করলে IP whitelist ও স্ট্রং পাসওয়ার্ড ব্যবহার করুন।
